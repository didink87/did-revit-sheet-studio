SHEET STUDIO - Revit 2026
=========================

HOW TO INSTALL (simple)
1. Close Revit.
2. Extract the WHOLE ZIP into one folder (do not run it from inside the ZIP).
3. Double-click Setup.bat, choose [1] Install.
4. Open Revit 2026 -> DID tab -> Sheet Studio.
   If an add-in security dialog appears, choose "Always Load".

HOW TO UNINSTALL
Double-click Setup.bat, choose [2] Uninstall.

FILE LOCATIONS
- Add-in    : %AppData%\Autodesk\Revit\Addins\2026\SheetStudio\
- Manifest  : %AppData%\Autodesk\Revit\Addins\2026\SheetStudio.addin
- Preferences: %AppData%\SheetStudio\
- Log: %LocalAppData%\SheetStudio\log\
